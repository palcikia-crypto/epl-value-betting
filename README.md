# ⚽ EPL Value Betting — End-to-End Prediction & Backtest Pipeline

Production-пайплайн: данные football-data.co.uk → leak-free фичи → XGBoost/LogReg →
value betting бэктест по Pinnacle closing odds → Walk-Forward → **честный вердикт**.

## Запуск

```bash
pip install -r requirements.txt
python3 run_pipeline.py          # данные → фичи → модели → бэктест → графики → отчёт
python3 iter2/run_iter2.py       # Kelly, CLV, ATP-теннис, прогнозы live 2025/26
python3 iter3/run_iter3.py       # мульти-лига, аблация (причинность), WTA, обновление live-пула
python3 iter4/run_iter4.py       # полный форвард-тест live-пула, Dixon-Coles, steam, стэкинг
python3 iter5/run_iter5.py       # точность по видам спорта, кривая обучаемости, совет моделей, НХЛ
python3 iter6/run_iter6.py       # live play-by-play НХЛ, back-to-back, стекинг против рынка, портфель
python3 dashboard/serve.py 8000  # web-дашборд: http://localhost:8000
```

## Анти-утечная дисциплина

- Признаки — **только информация до матча**: Elo до игры, форма по прошлым матчам, H2H до игры.
- Запрещённые колонки (`FTHG`, `FTAG`, `FTR`, `HS`, `AS`, `HST`, `AST`,…) в признаки не входят.
- Коэффициенты — только для бэктеста, не для обучения.
- Split строго хронологический: train 20/21–22/23 · val 23/24 · test 24/25.
- Выбор модели/порога — **только на validation**. Test трогается один раз.
- Калибровка — isotonic, кросс-валидированная внутри train (TimeSeriesSplit), чтобы validation оставалась чистой.

```

Test season: 2024/25
ROI: -36.09%          (bank 10 000 → 6 391)
Yield: -13.80%
Количество ставок: 341
Max Drawdown: 41.99%
Baseline ROI (фаворит): -15.66%
Test accuracy: 52.1%   (Validation accuracy: 55.5%)
```

### Test по порогам edge

| Стратегия | Ставок | ROI | Yield | Win rate | Max DD |
|---|---|---|---|---|---|
| edge > 5% | 341 | -36.09% | -13.80% | 24.9% | 41.99% |
| edge > 10% | 298 | -32.02% | -13.47% | 23.8% | ~40% |

### Стабильность (Walk-Forward: окно 2 сезона → следующий)

| Train | Test | ROI | Yield | Ставок |
|---|---|---|---|---|
| 20/21+21/22 | 22/23 | +1.66% | +0.50% | 363 |
| 21/22+22/23 | 23/24 | -24.71% | -8.37% | 332 |
| 22/23+23/24 | 24/25 | -53.28% | -23.59% | 350 |

### Red Flags
- Модель **не бьёт** baseline «всегда на фаворит рынка» (-36.1% против -15.7%).
- ROI волатилен между WF-окнами (от +1.7% до -53.3%) — модель нестабильна.
- Ставится ~90% матчей по edge>5% — фильтр почти не режет (probabilities не отделены от маржи).

### Заключение
> ❌ Модель не демонстрирует устойчивого преимущества.
> **Не рекомендуется для реальных ставок.**

Closing odds Pinnacle — эффективный рынок: «edge» модели против market prob исчезает
после маржи. Никакими порогами результат не «улучшался» (запрещено промптом).

## Итерация 3 (Причинность, мульти-лига, WTA, Live-пул)

`python3 iter3/run_iter3.py` — мульти-лиговый бэктест, аблация фич-блоков (причинность), WTA-тур, обновление live-пула. Дашборд: страница «Итерация 3».

### Данные
- **xG-proxy**: Understat и FBref закрыты анти-ботом/403 → использован открытый GitHub-датасет `xgabora/Club-Football-Match-Data` (удары/удары в цель >28 000 матчей, названия команд совпадают с football-data.co.uk) как прокси xG.
- **WTA**: tennis-data.co.uk, сезоны 2021–2025 (train ≤2023, val 2024 — 2 505 матчей, test 2025 — 2 351).

### Мульти-лиговый бэктест (train 5 сезонов → test 2024/25, threshold 0.05, flat 1%) — модель везде проигрывает базлайну
| Лига | Матчи | Ставок | ROI | Yield | Max DD | Baseline «фаворит» |
|---|---|---|---|---|---|---|
| E0 (Англия-1) | 380 | 341 | -36.09% | -13.80% | 42.0% | -15.66% |
| E1 (Чемпионшип) | 552 | 487 | -41.56% | -13.75% | 55.8% | -18.23% |
| SP1 (Испания-1) | 380 | 329 | -41.95% | -18.17% | 47.5% | +0.69% |
| D1 (Германия-1) | 306 | 271 | -40.32% | -19.37% | 41.3% | -15.62% |
| I1 (Италия-1) | 380 | 314 | -48.40% | -21.97% | 48.4% | -15.65% |
| F1 (Франция-1) | 306 | 269 | -25.50% | -12.32% | 34.7% | -10.15% |
| **POOLED** | 2304 | 2011 | **-95.03%** | **-15.12%** | 95.7% | — |

Модель одного класса (Elo+форма+сезон+H2H+XGBoost) проигрывает рынку в любой лиге.

### Причинная аблация (вал 2023/24, logloss — меньше лучше)
| Блок | Logloss |
|---|---|
| **Market only (имплайд-пробы Pinnacle)** | **0.9461** |
| Elo+форма | 0.9919 |
| Elo | 1.0083 |
| Сезонные метрики | 1.0024 |
| Форма | 1.0267 |
| H2H | 1.0277 |
| Удары/xG-proxy | 1.0245 |
| Full (all) | 0.9754 |
| **Full + удары/xG-proxy** | **0.9688** |

**Вывод о причинности:** рынок (коэффициенты Pinnacle) — сильнейший предиктор, судя по всему, уже включает всё, что мы можем посчитать по открытым данным (форму, Elo, составы, удары). Ни один наш блок, даже в сумме, не дотягивается по качеству до рынка. Удары в цель дают лучший прирост внутри модельного класса (all 0.9754 → all+shots 0.9688), но рынок уже закладывает их в коэффициенты — на бесплатных источниках «золотой жилы» в xG нет. Убитые источники изнутри песочницы: Understat (анти-бот), FBref (403) — без них недостижим уровень статистики игроков (здоровье, усталость, травмы) — там остаются только платные/API-источники.

### WTA (Test 2025, LogReg, threshold 0.02)
- 769 ставок, yield **-7.14%**, win rate 47.6%, Max DD 53.9% — edge в женском теннисе тоже нет.
- Точность прогноза исхода 67.5% — вполне приличная, но рынок эффективнее.

### 🔴 Live-пул EPL 2025/26 (paper trading, forward-тест)
- 185 сыгранных value-ставок (fair odds Pinnacle): побед 73, **ROI flat 1% +35.32%, yield +19.09%**.
- Monthly PnL (10 000 банк): Aug +1169, Sep +1013, Oct +948, Nov +1144, Dec +52, Jan **-794** — сильный старт с затуханием к зиме.
- Статистика: **+1.53σ (p≈0.13 при n=185)** — выше нуля, но **НЕзначимо** (для значимости нужно t≥2). Задача до конца сезона: досчитать пул до конца сезона (n ставок росет намного больше 185), добавить CLV-мониторинг против closing-линии, банк не поднимать.
- CSV-фид: `outputs/live_2526.csv` (обновляется каждым запуском).

### Итог 3 итерации
> ❗ «Золотой жилы» не найдено: рынок эффективен в E0/E1/SP1/D1/I1/F1 и в ATP/WTA.
> Единственный положительный аномальный участок — действующий live-пул 2025/26, но он статистически не значим (p≈0.13) и в нём наблюдается ретроградная динамика (Nov +1144 → Jan -794). Ждём конец сезона.

## Итерация 4 (Полный форвард-тест, Dixon-Coles, Steam, Стэкинг, Рекалибровка рынка)

`python3 iter4/run_iter4.py` — нестандартные подходы и завершение forward-теста. Дашборд: страница «Итерация 4».

### 1. Live-пул EPL 2025/26: сезон завершён — финальный форвард-тест
- 325 value-ставок (Pinnacle 185 + B365 140 там, где Pinnacle-фид обрывается), побед 118.
- **ROI flat 1% = +48.46%, yield = +13.66%, Max DD = 17.0%.**
- Но: **t = 1.41 (p ≈ 0.16) — НЕ значимо**; **CLV против closing-линии ≈ 0.000%** (положительных 44.3%) — на закрытии мы получаем ровно рыночную цену, «проскока» нет.
- Месяцы: Aug +1169, Sep +1013, Oct +948, Nov +1144, Dec +52, Jan −329, Feb −810, Mar +826, Apr −298, May +724.
- Вывод: плюсовой сезон = дисперсия на высоких коэффициентах, а не edge. Критерий доверия для сезона 2026/27: t ≥ 2 при ≥ 400 ставках И стабильно положительный CLV.
- CSV: `outputs/live_2526_full.csv` (все ставки с closing-линиями), кривая: `outputs/forward_curve.npy`.

### 2. Dixon-Coles (Пуассон-модель силы команд с затуханием времени)
- Классика (attack/defense силы, home-advantage, коррекция низких счётов rho, вес экспоненциального затухания xi, подбор xi на val).
- Val logloss 0.9435 — лучший из структурных моделей, но хуже чистого devig-рынка (0.9085).
- **Test 2024/25: logloss 1.0578, accuracy 45.3%, ROI −42.0% (343 ставки) vs baseline −15.7%** — силы команд не переносятся между сезонами без рынка.

### 3. Стэкинг модель × рынок
- LogReg поверх лог-отношений (model/market) на val: logloss стэка 0.9540 — хуже обоих входов (market 0.9085, model 0.9693).
- Test ROI стэка −36.97%. Линейный стэк с рынком не помогает — рыночный сигнал доминирует.

### 4. Steam-фактор (движение opening → closing Pinnacle, 5 сезонов EPL)
- Chase (деньги на исход, ≥2%): 1636 ставок, yield **+1.24%**, t=0.30 — незначимо.
- Chase ≥4%: yield −1.20% (t=−0.25). Fade ≥2%: yield −8.77% (t=−2.06).
- Движение линии почти информативно, но на закрытии всё уже в цене — арбитража нет.

### 5. Перекалибровка рынка (isotonic по прошлым исходам)
- Val: recal 0.9119 vs market 0.9085 (хуже). Test: recal 0.9686 vs market 0.9703 (в шуме).
- ROI по «рекалибровочным» value-ставкам: −12.35% (206 ставок, yield −7.06%).
- Вывод: Pinnacle правильно калиброван сам по себе; эксплойта систематического мискэла нет.

### Итог 4 итерации
> ❌ Ни один из нестандартных подходов (Dixon-Coles, стэк, steam, рекалибровка) не даёт значимого edge против Pinnacle closing.
> Единственный плюс (live-пул 2025/26, ROI +48.5%) при t=1.41 и CLV≈0 признается дисперсией. Для 2026/27 пул перезапускается с заранее заданным критерием значимости.

### 2. «Хватит ли года истории?» — НЕТ
Обучение на 1/2/3/4/5 сезонах → test 2024/25: logloss 1.0616 → 1.0462 → 1.0211 → 1.0104 → **0.9947** (accuracy 50.0% → 52.4%).
Кривая монотонная, плато не достигнуто; рынок (0.9703) всё равно впереди — пробел закрывается не историей, а данными, которых нет в открытом доступе (составы, травмы, игровое время).

### 3. Калибровка
- ECE (3 класса, 10 бинов): модель ≈ 0.81, рынок 0.76; Brier: модель 0.596 vs рынок 0.579.
- Изотоническая калибровка заметно улучшает модель (Brier 0.630 → 0.596 при росте истории), но качество рыночных вероятностей недостижимо на открытых данных — вторая причина убыточности value-ставок.

### 4. Совет моделей («агенты»)
- Агенты: XGBoost (вес 0.32), Dixon-Coles (0.33), рынок (0.34) — веса ∝ 1/val_logloss (leak-free).
- Test: совет acc 50.8%, logloss 0.9939 — **хуже чистого рынка** (53.9%, 0.9703). ROI value-ставок совета −36.1%.
- Вывод: агрегация слабых агентов не создаёт уверенности выше рынка. Код оставлен как каркас для будущих агентов.

### Итог 5 итерации
> Точность системы честно измерена по трём видам спорта: система стабильна, leak-free и монотонно улучшается с историей, но по всем метрикам (accuracy, logloss, Brier, ECE) уступает Pinnacle. Для профита нужен не «более хитрый ML», а данные, которых нет в открытом доступе.

## Итерация 6 (LIVE-данные НХЛ, стекинг против рынка, портфельные стратегии)

`python3 iter6/run_iter6.py` — live play-by-play, причинность расписания, divergence-анализ, портфель. Дашборд: страница «Итерация 6».

### 1. LIVE play-by-play НХЛ (692 игры из открытого API)
- Состояния матча каждые ~4 мин (счёт, время, разница бросков в створ), train 310 игр / test 382.
- Кривая точности: 59.1% на 10-й минуте → 78.5% на 40-й → 93.1% к 63-й. Классическое накопление информации.
- АБЛЯЦИЯ: «счёт+время» без бросков 74.1% vs 74.4% с бросками (AUC 0.84 vs 0.84) — **броски поверх счёта не добавляют информации**: всё уже «в цене».

### 2. Причинность расписания: back-to-back (2 915 матчей)
- Гость на B2B (вторые сутки подряд) при свежем хозяине → победы хозяев **62.7%** (n=217, 95% ДИ 56.1–68.8) против базовых 52.7% (+8.7пп) — **самый сильный фактор, найденный за все 6 итераций**.
- Обратная ситуация (хозяин на B2B): −7.0пп, но n=66, ДИ широкий (z=−1.40).
- Модель с фичами расписания (54.1%) НЕ обошла чистый Elo (56.0%): 619 матчей train мало, и рынок график давно знает.

### 3. Стекинг против рынка: анализ расхождений (EPL тест 2024/25)
- corr(d, попадание) = 0.015 — расхождение модели с рынком НЕ несёт сигнала.
- В главной «value»-полосе d∈[0.05, 0.09) фактические заходы 18.8% против обещанных рынком 28.4% — модель ошибается вдвое чаще, чем думает. Расхождение с рынком = ошибка модели, а не эдж.

### 4. Портфельные стратегии («ставить на несколько матчей — заберу выигрыш»?)
- Все value-ставки (338): ROI −21.7%; топ-3 в день (236): −23.6%; 1 ставка в день (104): −4.6% (n мало — шум).
- Монте-Карло (4 000 сим., без эджа, 338 ставок): медианный финал 9 431 из 10 000, P(плюс) 43.6%, P5 = 5 401.
- **Вывод: диверсификация не создаёт эдж — она ускоряет реализацию отрицательного матожидания. Ставить больше = надёжнее минус.**

## Итерация 7 (Архивные линии НХЛ, тюнинг Elo, торгуемое B2B-правило)

Запуск: `python3 iter7/run_iter7.py` → `outputs/iter7.json` (недостающая история НХЛ докачивается автоматически), графики `python3 src/charts_iter7.py`, страница `dashboard/iter7.html`.

### 1. Новый источник: настоящие коэффициенты через Wayback Machine
- Букмекерские линии не отдаются бесплатно, но снимки таблиц SBRforum лежат в web.archive.org (CDX API + id_-replay URL). Скачаны и распарсены xlsx: **НХЛ 2021/22 полный сезон (1 401 игра)** и **окт–ноя 2022/23 (342 игры)** с American Open/Close. Snapshot-URL сохранены в `data/nhl_odds/snapshots.json` (и `outputs/nhl_odds_snapshots.json`).
- Параллельно добрана официальная история NHL API 2019–2023: итоговая база **7 488 игр за 7 сезонов** (`outputs/nhl_games_ext.csv` + старый `nhl_games.csv`).

### 2. Тюнинг Elo (K, home-adv, MOV, сезонный rollback)
- Грид 72 комбинаций; выбор строго по вал-2023; тест — 2024 → апр 2025 (n=2 295). Лучшие параметры: **K=30, home_adv=40, MOV=0.3, rollback=0.2**.
- Точность: val 2023 **59.47%**, test **58.78%** (logloss 0.6631), календарный 2024 **59.11%**.
- Против плоского Elo итерации 5 (55.95%) — **+3 п.п.** от длинной истории + MOV + rollback. Рынок (devig close) на matched-выборке окт–ноя 2022/23: 58.94% vs Elo 57.28% — разрыв сократился с ~3 до ~1.7 п.п., но не закрыт.

### 3. B2B-эффект: статистическая значимость
- Пул 7 сезонов: гость B2B + хозяин свежий → побед хозяина **59.0%** против **53.8%** базовых (n=1 103 vs 5 604). Двухдолевой z-тест: **z=3.21, p=0.0014 — значимо** (в итерации 6 было p≈0.02 по n=217).
- Хозяин B2B → победы хозяина всего 41.7% (n=360) — эффект бьёт обе стороны; стабилен по каждому из 7 сезонов.

### 4. B2B-правило против настоящих линий
- Правило пре-зарегистрировано до прогона: гость B2B → ставка на хозяина; хозяин B2B → ставка на гостя (NHL moneyline, SBR Close).
- **VAL 2021/22: 100 ставок, yield +6.84%** (ROI +7.2%, DD 6%). **TEST 2022/23: 249 ставок, yield +6.25%** (ROI +16.9%). Пул: **349 ставок, ROI +25.3%, yield +6.37%** — но t=1.37, p=0.17 (нужен больше объёма для строгого вывода).
- Рынок частично закладывает B2B: p(хозяина) сдвигается Open→Close на +1.5…+2.6 п.п. на играх с уставшим гостем против ≈0 на остальных — остаточная неэффективность ≈ половина эффекта.
- Elo+B2B-поправка (δ из пре-2024): logloss на test 2024–2025 0.6631 → 0.6619 — маленькое, но причинно объяснимое улучшение.

### Вердикт
B2B — первый за проект фактор, который (а) статистически значим на 7 488 играх, (б) плюсует против настоящих коэффициентов в двух независимых окнах. Точность НХЛ-модели поднята с 56% до 59.1%. Для строгого вывода нужны ещё 1–2 сезона или больше архивных линий.
